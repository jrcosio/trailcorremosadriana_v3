# Decisiones aprobadas por el propietario

Esta tabla evita que una nueva sesión de desarrollo deshaga los ajustes de la propuesta.

| Elemento | Decisión final |
|---|---|
| Título de portada | Sustituir «LA MONTAÑA NOS UNE.» por «TRAIL PENASAGRA» y aumentarlo ligeramente |
| Color del título | «TRAIL» blanco; «PENASAGRA» naranja; dos líneas |
| Frase de causa | «Corremos por Adriana.» más grande |
| Icono junto a la frase | Silueta de la niña aportada por el propietario, en naranja; retirar el corazón de esa ubicación |
| Texto sobre el contador | Eliminar «TRAIL PEÑASAGRA 2027» de esa ubicación |
| Botón superior | «INSCRIPCIONES» y acceso a `/inscripciones` |
| Dorsal en portada | Bloque mucho más vistoso que la línea gris original |
| Dorsal en la causa | Tarjeta destacada y mismo destino de pago que en portada |
| Pago del dorsal | URL específica de la plataforma de inscripciones, configurable en el panel; activa con apertura global y URL válida |
| Mientras no esté disponible | Aviso «Próximamente disponible» sin desviar a Contacto |
| Patrocinadores | Imágenes mucho mayores en portada y página de entidades, conservando proporción |
| Colaboradores | Sección diferenciada con el mismo modelo de imagen y enlace que Patrocinadores |
| Fotos | Reutilizar las fotografías reales de la web y el proyecto |
| Backend definitivo | FastAPI, PostgreSQL, SQLAlchemy/Alembic, R2/S3 y Docker Compose; implementación pendiente a cargo del siguiente agente |
| Administración | Fuera de navegación pública, con usuario/contraseña y gestión persistente |
| Próxima edición | No inventar fecha ni datos oficiales de 2027 |
| Clasificaciones | Un CSV por carrera y edición; los datos importados generan la tabla de participantes |
| Dorsal Solidario en clasificaciones | No tiene clasificación y no debe aparecer entre las carreras o resultados de esa sección |

Se puede mejorar implementación y accesibilidad sin cambiar estas decisiones. Cualquier cambio visual sustancial debe partir de una nueva instrucción del propietario.
